# External resources

## Guides to incremental reading

- [A short guide to incremental reading](https://www.supermemo.wiki/en/learning/incremental-reading): a good first read.
- [Incremental reading in SuperMemo](https://help.supermemo.org/wiki/Incremental_reading): the complete (and long) original guide. Many of the ideas carry over, even though the software is different.

## Writing good cards

- [20 rules of knowledge formulation](https://supermemo.guru/wiki/20_rules_of_knowledge_formulation): how to write cards you'll actually remember.
- [Atomic memory](https://supermemo.guru/wiki/Atomic_memory): why smaller cards work better.

## Spaced repetition

- [The FSRS algorithm](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm): how cards are scheduled.

## Tools for importing

- [Obsidian Web Clipper](https://obsidian.md/clipper): a browser extension from the Obsidian team that saves web pages to your vault. The same feature is built into Obsidian's web viewer (**⋮ → Save to vault**).
- [MarkDownload](https://github.com/deathau/markdownload): a browser extension that converts web pages to Markdown. It works better than Web Clipper on some sites.
- [Marker](https://github.com/datalab-to/marker): converts PDFs to Markdown.

## Obsidian plugins that work well with this one

- [Auto Link Title](https://github.com/zolrath/obsidian-auto-link-title): fills in a page's title when you paste a link, which is handy for [embedding videos](/guide/importing#videos).
